# 장애 진단 매트릭스

증상은 원인 하나와 일대일 대응하지 않습니다. 표의 “첫 검사”부터 증거를 모으고, 결과에 따라 다음 단계로 이동합니다.

| 증상 | 첫 검사 | 가능한 원인 | 다음 검사 |
|---|---|---|---|
| 호스트 이름 해석 실패 | `getent hosts NAME` | 서비스 이름 오타, 공통 네트워크 없음, 컨테이너 종료 | `docker compose config`, 네트워크 검사 |
| 연결 거부 | `ss -ltnp`, `compose ps` | 프로세스 미기동, 잘못된 포트, 루프백만 바인드 | 서비스 로그, 설정 파일 |
| 연결 제한 시간 초과 | `curl --connect-timeout`, TCP 검사 | 방화벽, 네트워크 단절, 과부하 | 경로 정보, 호스트 방화벽, 자원 사용 |
| TLS 인증서 오류 | `curl -v`, `openssl s_client` | SAN 불일치, 만료, 신뢰 CA 없음 | `openssl x509`, 서버 이름 |
| HTTP 404 | `curl -i`, Nginx `-T` | 잘못된 `location`·`root`·경로 | 컨테이너 파일 존재, `try_files` |
| HTTP 403 | `id`, `namei -l PATH` | 파일·상위 디렉터리 권한, 읽기 전용 정책 | 마운트와 실행 사용자 |
| HTTP 500 | 애플리케이션 로그 | PHP 예외, 데이터베이스 쿼리, 설정 누락 | FPM 로그, 데이터베이스 연결 |
| HTTP 502 | 애플리케이션 상태와 FPM 연결 확인 | 업스트림 이름·포트, FPM 종료, 프로토콜 오류 | 게이트웨이 DNS/TCP, 애플리케이션 로그 |
| `Primary script unknown` | 양쪽 `ls -l` | `SCRIPT_FILENAME` 불일치, 공유 경로 오류 | Nginx 문서 루트와 애플리케이션 경로 |
| 데이터베이스 접근 거부 | 애플리케이션 DSN과 사용자 | 비밀번호, 호스트 권한, 초기화 실패 | 비밀값 출처, `SELECT User,Host` |
| 알 수 없는 데이터베이스 | 데이터베이스 목록 | `DB_NAME` 오타, 초기 SQL 미실행 | 데이터베이스 최초 실행 로그 |
| 테이블을 찾지 못함 | 스키마 변경 상태 | 초기화 실패, 다른 데이터베이스 접속 | `schema_version`, 애플리케이션 로그 |
| 데이터가 초기화됨 | `inspect .Mounts` | 새 프로젝트 볼륨, `down -v`, 마운트 경로 오류 | `docker volume ls`, 셸 기록 |
| 컨테이너 즉시 종료 | `compose ps -a`, 로그 | PID 1 종료, 백그라운드 서버, 필수값 누락 | 이미지 시작 명령, 종료 코드 |
| 재시작 반복 | `RestartCount`, 최초 로그 | 설정 오류, 충돌, 상태 검사와 재시작 혼동 | 재시작 정책 임시 해제 |
| 비정상인데 요청 성공 | 상태 검사 기록 | 검사 경로·도구·권한 오류 | 검사 명령을 직접 실행 |
| 정상인데 기능 실패 | 기본 동작 검사 | 상태 검사가 너무 얕음 | 애플리케이션·데이터베이스 실제 읽기 경로 |
| 애플리케이션은 정상, PHP만 502 | FPM 연결 확인과 `APP_UPSTREAM` | FastCGI 포트 오타 | 게이트웨이 템플릿 렌더링 결과 |
| 데이터베이스 CPU 증가 | 프로세스 목록, 느린 쿼리 | 전체 탐색, 잠금, 연결 폭증 | `EXPLAIN`, 인덱스, 풀 크기 |
| 데이터베이스 메모리 증가 | 버퍼 풀, 연결 수 | `max_connections`, 큰 세션별 버퍼 | 연결 풀, 메모리 제한 |
| 종료가 오래 걸림 | PID 트리, 중지 로그 | 셸 PID 1, 시그널 미전달, 긴 요청 | 배열 형식, 정상 종료 제한 시간 |
| 백업은 있으나 복원 실패 | 빈 환경 복원 | 불완전한 덤프, 권한, 버전 차이 | 덤프 옵션과 복원 로그 |

## 기본 순서

```text
Compose 모델
→ 컨테이너 상태
→ 최초 로그
→ PID 1과 worker
→ listen
→ DNS
→ TCP
→ 실제 프로토콜
→ 설정·secret
→ 파일·권한
→ volume·DB 상태
```
