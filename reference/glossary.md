# 컴퓨터 네트워크 용어집

본문에서 같은 단어를 다른 범위로 혼동하기 쉬운 항목을 짧게 정리했습니다.

| 용어 | 이 가이드에서의 의미 |
|---|---|
| 종단점 | 통신 상태를 가진 종단이며 IP·포트 또는 Connection ID 등으로 식별될 수 있음 |
| 인터페이스 | 운영체제나 장비가 패킷을 송수신하는 논리·물리 연결점 |
| 링크 | 한 번의 링크 계층 전달이 가능한 범위 |
| 프레임 | 링크 계층 전송 단위 |
| 패킷 | 보통 IP 계층 전송 단위이며 문맥상 일반 단위로도 사용됨 |
| segment | 보통 TCP 전송 단위 |
| 데이터그램 | UDP 또는 비연결형 패킷 단위를 가리키는 말 |
| 프리픽스 | 주소 공간의 연속된 상위 비트 범위 |
| 서브넷 | 같은 IP 프리픽스를 공유하는 논리 네트워크 |
| 다음 홉 | 현재 장비가 패킷을 넘길 바로 다음 라우터 또는 직접 연결 목적지 |
| 게이트웨이 | 다른 네트워크로 전달하는 라우터를 일상적으로 부르는 표현 |
| 경로 | 목적지 프리픽스와 다음 홉·인터페이스·속성의 결합 |
| 전달 | 이미 선택된 테이블을 사용해 패킷을 다음 홉으로 보내는 동작 |
| routing | 경로 정보를 학습·계산·정책 적용하는 과정까지 포함하는 표현 |
| 흐름 | 일정한 키를 공유하는 패킷 집합이며 키 정의는 시스템마다 다름 |
| 튜플 | 프로토콜, 출발지·목적지 주소와 포트의 조합 |
| RTT | 송신에서 관련 응답·ACK까지의 왕복 시간 표본 |
| RTO | 재전송을 시작하기 위한 타이머 값 |
| MTU | 한 링크에서 상위 packet으로 실을 수 있는 최대 크기 |
| MSS | 한 종단점이 상대에게 광고하는 방향별 TCP 페이로드 상한 |
| 혼잡 | 경로 자원보다 트래픽 수요가 커 큐·손실·표시가 생기는 상태 |
| backpressure | 소비 한계를 생산자 방향으로 전달하는 제어 |
| stateful | 과거 packet이나 연결 상태를 저장해 다음 결정을 내리는 방식 |
| 멱등성 | 같은 연산을 반복해도 효과가 한 번과 같은 애플리케이션 계약 |
| multiplexing | 여러 상위 흐름을 하나의 하위 연결이나 매체에 함께 싣는 방식 |
| head-of-line blocking | 앞선 단위가 준비되지 않아 뒤 단위도 전달되지 못하는 현상 |

프로토콜 문서와 도구가 패킷, 데이터그램과 연결을 더 엄밀하거나 다른 의미로 사용할 수 있습니다. 보고서에서는 사용한 키와 범위를 명시하세요.
