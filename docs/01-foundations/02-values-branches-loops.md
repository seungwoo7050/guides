# 값·분기·반복: 여러 입력을 처리해 결과 만들기

프로그램은 값을 저장하고, 조건에 따라 실행할 경로를 선택하며, 반복을 통해 상태를 계속 갱신합니다. 문법을 하나씩 외우기보다 먼저 "어떤 값을 저장하고, 어떤 조건에서 어떻게 바꿀 것인가"를 정리하는 편이 안전합니다.

## 기본 값과 타입

```c
int count = 0;
long sum = 0;
double average = 0.0;
char grade = 'A';
```

타입은 값이 가질 수 있는 범위와 적용할 수 있는 연산의 규칙을 정합니다. C의 정수형 크기와 범위는 구현에 따라 달라질 수 있으므로 임의로 가정해서는 안 됩니다. 필요한 경우 `<limits.h>`에 정의된 `INT_MIN`, `INT_MAX`, `LONG_MIN`, `LONG_MAX` 등을 사용합니다.

자동 저장 기간을 갖는 지역 변수는 자동으로 0으로 초기화되지 않습니다.

```c
int count;      /* 초기화되지 않음 */
count += 1;     /* 초기화되지 않은 값을 읽음 */
```

개수나 합처럼 이전 값을 바탕으로 계속 갱신하는 변수는 선언할 때 초기값을 지정합니다.

## 식과 비교

조건을 값으로 표현할 수 있습니다.

```c
int is_even = value % 2 == 0;
int inside = value >= minimum && value <= maximum;
```

C에서는 `0`을 거짓으로, `0`이 아닌 값을 참으로 해석합니다. 따라서 비교 결과를 다시 `== 1`과 비교할 필요는 없습니다.

```c
if (is_even)
{
    even_count++;
}
```

`=`는 값을 대입하는 연산자이고 `==`는 두 값을 비교하는 연산자입니다. 컴파일러 경고를 활성화하면 조건식에서 발생하는 실수의 일부를 발견할 수 있지만, 모든 논리 오류를 찾아 주는 것은 아닙니다.

## 분기

조건에 따라 서로 다른 동작을 선택할 수 있습니다.

```c
if (value < 0)
{
    negative_count++;
}
else if (value == 0)
{
    zero_count++;
}
else
{
    positive_count++;
}
```

분기는 입력을 서로 다른 경우로 나누어 처리합니다. 조건이 서로 겹친다면 검사 순서에 따라 결과가 달라질 수 있으므로, 각 입력이 어느 경로를 거치는지 확인해야 합니다.

`switch`는 하나의 정수형 값이나 열거형 값을 기준으로 여러 경우를 명확하게 나눌 때 유용합니다. 의도하지 않았는데 `break`를 빠뜨리면 다음 `case`의 코드까지 이어서 실행되는 fallthrough가 발생할 수 있습니다.

## 반복과 불변식

다음 코드는 명령행 인자를 앞에서부터 하나씩 순회합니다.

```c
for (int index = 1; index < argc; index++)
{
    printf("%s\n", argv[index]);
}
```

반복문을 이해할 때는 매 반복의 시작과 끝에서 계속 참이어야 하는 조건을 문장으로 적어 보는 것이 좋습니다.

```text
index는 아직 처리하지 않은 첫 번째 인자의 위치다.
count는 지금까지 처리한 유효한 값의 개수다.
sum은 지금까지 처리한 값의 합이다.
minimum과 maximum은 유효한 값을 하나 이상 처리한 뒤에만 의미가 있다.
```

이처럼 반복 과정에서 계속 유지되어야 하는 조건을 **반복 불변식**이라고 합니다.

좋은 불변식은 반복을 시작하기 전부터 성립하고, 반복을 한 번 수행한 뒤에도 유지되어야 합니다. 반복이 끝났을 때는 이 불변식과 종료 조건을 이용해 원하는 결과가 만들어졌음을 설명할 수 있어야 합니다.

## 최솟값과 최댓값 초기화하기

입력 범위를 임의로 가정해 큰 상수를 최솟값의 초기값으로 사용해서는 안 됩니다.

```c
long minimum = 999999; /* 입력 범위가 달라지면 올바르게 동작하지 않음 */
```

대신 처음 들어온 유효한 값을 최솟값과 최댓값의 초기값으로 사용합니다.

```c
if (count == 0)
{
    minimum = value;
    maximum = value;
}
else
{
    if (value < minimum)
    {
        minimum = value;
    }

    if (value > maximum)
    {
        maximum = value;
    }
}

count++;
```

핵심은 최솟값과 최댓값에 임의의 값을 넣는 것이 아니라 **"아직 유효한 값을 하나도 처리하지 않았다"는 상태를 별도로 표현하는 것**입니다.

여기서는 `count == 0`이 그 상태를 나타냅니다.

## 정수 나눗셈과 타입 변환

다음 두 식은 같은 결과를 만들지 않을 수 있습니다.

```c
double wrong = sum / count;
double right = (double)sum / count;
```

두 피연산자가 모두 정수형이면 나눗셈도 정수 연산으로 수행됩니다. 소수점 이하 값은 이 단계에서 이미 사라지므로, 결과를 나중에 `double`에 저장해도 복구되지 않습니다.

평균처럼 실수 나눗셈이 필요하다면 연산 전에 적어도 한쪽 피연산자를 부동소수점 타입으로 변환해야 합니다.

또한 나눗셈을 수행하기 전에 `count == 0`인지 반드시 확인해야 합니다.

## 오버플로도 프로그램의 계약으로 다루기

각 입력값이 모두 `long`의 범위 안에 있더라도 여러 값을 더한 결과는 그 범위를 벗어날 수 있습니다.

C에서 부호 있는 정수 오버플로는 정의되지 않은 동작이므로, 합을 구하는 프로그램이라면 오버플로가 발생했을 때 어떻게 처리할지도 프로그램의 계약에 포함해야 합니다.

```c
if ((value > 0 && sum > LONG_MAX - value) ||
    (value < 0 && sum < LONG_MIN - value))
{
    /* 덧셈을 수행하지 않고 실패 처리 */
}
else
{
    sum += value;
}
```

중요한 점은 오버플로가 발생한 뒤 결과를 검사하는 것이 아니라 **위험한 연산을 수행하기 전에 발생 가능성을 확인하는 것**입니다.

이미 부호 있는 정수 오버플로가 발생했다면 그 이후의 값을 이용해 문제를 판단할 수 없습니다.

## 경계값으로 검사하기

일반적인 입력만 확인하면 조건이 바뀌는 경계에서 발생하는 오류를 놓치기 쉽습니다.

다음과 같은 입력을 따로 확인합니다.

* 유효한 입력이 하나뿐인 경우
* 같은 값이 여러 번 들어오는 경우
* 음수와 `0`이 포함된 경우
* `LONG_MIN`과 `LONG_MAX`
* 합이 표현 가능한 최솟값이나 최댓값에 정확히 도달하는 경우
* 다음 덧셈에서 표현 가능한 범위를 벗어나는 경우

각 사례에 대해 예상하는 stdout, stderr와 종료 상태를 미리 정합니다.

이렇게 하면 단순히 "실행된다"는 사실이 아니라 정상 입력, 경계값과 실패 조건에서 프로그램이 정해 둔 계약대로 동작하는지를 확인할 수 있습니다.
