# 정확성, 불변식과 종료

## 학습 목표

- 함수 계약과 알고리즘 상태의 의미를 분리한다.
- 반복 불변식과 수학적 귀납법으로 부분 정확성을 설명한다.
- 종료를 별도의 주장으로 증명한다.
- 실행 가능성과 최적성을 구분한다.
- 반례와 테스트가 증명을 대신하지 않는 이유를 이해한다.

## 선행 개념

[문제 계약](01-problem-contracts-and-counterexamples.md), 반복문 상태와 수학적 귀납법의 기초를 알고 있어야 한다.

## 핵심 모델

알고리즘의 완전한 정확성은 두 주장으로 나뉜다.

```text
부분 정확성: 종료한다면 결과가 계약을 만족한다.
종료성: 모든 허용 입력에서 실제로 종료한다.
```

최적화 문제는 다시 나뉜다.

```text
실행 가능성: 반환값이 모든 제약을 만족한다.
최적성: 더 좋은 실행 가능한 해가 존재하지 않는다.
```

## 1. 반복 불변식

불변식은 각 반복의 같은 지점에서 계속 참인 문장이다.

증명 구조:

```text
초기화: 첫 반복 전에 불변식이 참이다.
유지: 한 번의 반복이 불변식을 보존한다.
종료: 종료 조건과 불변식을 합치면 후조건이 나온다.
```

### 이분 탐색 예

반열린 구간 `[lo, hi)`에서 첫 번째 `A[i] >= target` 위치를 찾는다고 하자.

```text
불변식 1: lo 앞의 모든 원소는 target보다 작다.
불변식 2: hi부터 뒤의 모든 원소는 target 이상이다.
불변식 3: 0 <= lo <= hi <= n이다.
```

`lo == hi`가 되면 두 경계가 만나는 위치가 첫 삽입 위치다.

## 2. 재귀 귀납

```text
기저: 가장 작은 입력에서 직접 정확하다.
귀납 가정: 더 작은 하위 문제의 결과가 정확하다.
결합: 하위 결과로 현재 문제의 계약을 만족한다.
종료: 각 호출에서 측도(measure)가 감소한다.
```

측도는 배열 길이, 남은 정점 수, 미결정 변수 수처럼 음이 아닌 정수로 잡는 경우가 많다.

## 3. 교환 논리

그리디 선택의 최적성을 보일 때 다음 형태를 사용한다.

1. 임의의 최적해 `O`를 잡는다.
2. `O`가 그리디의 첫 선택을 포함하지 않으면, `O`의 일부를 그리디 선택으로 바꾼다.
3. 실행 가능성과 목적값이 나빠지지 않음을 보인다.
4. 첫 선택을 공유하는 최적해가 존재하므로 남은 부분 문제에 같은 논리를 적용한다.

“가장 좋아 보이므로 고른다”는 설명은 교환 논리가 아니다.

## 4. 절단 성질과 완화 불변식

그래프 알고리즘은 도메인에 맞는 불변식을 사용한다.

- 최소 스패닝 트리: 어떤 절단을 가로지르는 최소 가중치 간선은 안전한 선택이다.
- Dijkstra: 확정 집합에서 꺼낸 정점의 거리는 음수 간선이 없을 때 최단 거리다.
- Bellman–Ford: `k`번째 반복 뒤에는 간선 수가 최대 `k`인 최단 경로가 반영된다.
- 최대 유량: 잔여 그래프의 각 증가 경로가 용량과 흐름 보존을 유지한다.

## 5. 전조건이 증명의 일부다

정확성 주장은 전조건 안에서만 유효하다.

- 이분 탐색: 입력이 정렬됨
- Dijkstra: 음수 가중치 없음
- 위상 정렬: 결과 전체를 원하면 DAG
- 해시 기대 비용: 해시 분포와 resize 정책에 대한 가정
- 재귀 DFS: stack 깊이를 감당할 수 있음

전조건을 코드가 검증하는지, 호출자 계약으로 남기는지 명시한다.

## 6. 테스트와 증명의 역할

테스트는 다음에 강하다.

- 구현이 의사코드와 다르게 작성된 결함
- 경계값, 잘못된 인덱스, overflow
- 증명에서 빠뜨린 전조건을 드러내는 반례

증명은 다음에 강하다.

- 무한한 허용 입력 전체에 대한 구조적 근거
- 왜 특정 상태만 유지해도 충분한지 설명
- 최적성이나 종료성의 근거

둘 중 하나로 다른 하나를 대체하지 않는다.

## 7. 정확성 설명 템플릿

```text
계약:
전조건:
상태의 의미:
불변식:
초기화:
유지:
종료:
후조건:
비용:
실패 조건:
```

최적화 문제라면 다음을 추가한다.

```text
실행 가능성:
최적성 근거:
동점 처리:
```

## 연결 실습

[분석과 반례 exercise](../../exercises/01-analysis-and-counterexamples/README.md)에서 lower bound의 반복 불변식 또는 구간 선택의 교환 논리를 초기화·유지·종료 순서로 작성한다.

## 완료 기준

- 불변식이 매 반복 경계에서 참인지 작은 입력으로 판정할 수 있다.
- 초기화·유지·종료가 후조건으로 이어지는 논리를 빠짐없이 연결한다.
- 테스트가 찾는 반례와 증명이 보장하는 입력 범위를 구분해 설명한다.

## 실패 조건

- 불변식이 “알고리즘이 잘 동작한다”처럼 검증 불가능한 문장이다.
- 종료 조건을 결과의 정확성과 혼동한다.
- 그리디 선택의 실행 가능성만 보이고 최적성은 보이지 않는다.
- Dijkstra 증명에서 음수 간선 전조건을 누락한다.
- 테스트 수가 많다는 이유로 증명을 생략한다.
