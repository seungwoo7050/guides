# 점근 분석

## 학습 목표

- 입력 크기와 비용 모델을 먼저 정의한다.
- `O`, `Ω`, `Θ`와 최악·평균·기대·상각 비용을 구분한다.
- 반복문, 자료구조 연산, 출력 크기를 포함해 시간과 공간을 계산한다.
- 여러 입력 변수와 희소·밀집 구조를 보존해 표현한다.

## 선행 개념

[문제 계약과 반례](01-problem-contracts-and-counterexamples.md)의 입력 크기 정의와 기본적인 합·곱·로그 표기를 먼저 이해해야 한다.

## 핵심 모델

점근 분석은 실제 실행 시간을 맞히는 일이 아니다. 입력이 커질 때 어떤 자원이 어떤 비율로 증가하는지 설명하는 일이다.

```text
입력 크기 → 세는 기본 연산 → 연산 횟수의 상·하한 → 추가 공간
```

## 1. `n`이 무엇인지 먼저 정한다

- 배열: 원소 수 `n`
- 문자열 검색: 본문 길이 `n`, 패턴 길이 `m`
- 그래프: 정점 수 `V`, 간선 수 `E`
- 큰 정수: 값이 아니라 비트 수
- 출력 열거: 입력 크기와 출력 개수

`O(V)`라고 쓰기 전에 간선을 읽는 비용이 빠지지 않았는지 확인한다. 인접 리스트 순회는 보통 `Θ(V+E)`다.

## 2. 점근 표기

충분히 큰 입력에서 다음을 뜻한다.

```text
f(n) = O(g(n))   : 상수배 g보다 커지지 않는 상한
f(n) = Ω(g(n))   : 양의 상수배 g보다 작아지지 않는 하한
f(n) = Θ(g(n))   : 두 조건을 모두 만족하는 같은 차수
```

`3n² + 10n + 7`은 `Θ(n²)`다. `O(n³)`도 참이지만 알고리즘의 증가율을 불필요하게 느슨하게 표현한다.

## 3. 입력 경우와 분석 방법을 분리한다

```text
최악 시간 : 같은 크기의 모든 입력 중 최대 비용
평균 시간 : 명시한 입력 분포에 대한 평균
기대 시간 : 알고리즘 내부 무작위성에 대한 기댓값
상각 시간 : 연산열 전체 비용을 연산 수에 배분
```

해시 조회의 기대 비용과 동적 배열 append의 상각 비용은 서로 다른 주장이다. “평균적으로 빠르다”라고 뭉뚱그리지 않는다.

## 4. 합으로 반복문을 계산한다

독립 중첩 반복은 곱이지만, 경계가 달라지면 합을 세운다.

```text
for i = 1 .. n:
    for j = 1 .. i:
        work()
```

작업 수는 `1 + 2 + ... + n = Θ(n²)`다.

두 포인터가 각각 한 방향으로만 이동하면 중첩된 `while`처럼 보여도 총 이동 횟수는 `O(n)`일 수 있다. 코드를 들여쓰기 깊이로 분석하지 말고 상태가 몇 번 변하는지 센다.

## 5. 자료구조 연산을 포함한다

다음은 자주 누락되는 비용이다.

- 길이 `k` 문자열·배열 복사: `Θ(k)`
- 정렬: 비교 비용을 `C`라 하면 보통 `O(n log n · C)`
- heap push/pop: `O(log n)`
- 균형 트리 탐색: `O(log n)`
- 해시 조회: 기대 `O(1)`, 최악 `O(n)` 가능
- 동적 배열 중간 삽입·삭제: `O(n)`
- 재귀 stack: 깊이에 비례한 공간

## 6. 출력 민감 비용

모든 답을 출력하는 문제는 출력 개수보다 빨라질 수 없다.

- 그래프의 모든 간선 출력: `Ω(E)`
- 모든 부분집합 출력: `Ω(2^n)`
- 문자열의 모든 일치 위치 출력: `Ω(k)`

따라서 `O(n+k)`처럼 입력과 출력 크기를 함께 쓰는 표현이 필요하다.

## 7. 추가 공간과 전체 공간

입력 자체가 차지하는 공간과 알고리즘이 추가로 사용하는 공간을 구분한다.

```text
입력 그래프: Θ(V+E)
방문 배열: Θ(V)
BFS queue: 최악 Θ(V)
추가 공간: Θ(V)
전체 보관 공간: Θ(V+E)
```

재귀 호출은 숨은 공간이 아니다. 깊이 `n` 재귀는 `Θ(n)` stack을 사용한다.

## 8. 분석 검토표

- 입력 변수마다 의미가 적혀 있는가?
- 최악·기대·상각 중 무엇인지 명시했는가?
- 라이브러리 호출과 복사를 포함했는가?
- 출력 크기 하한을 포함했는가?
- 정수 연산을 상수 시간으로 보는 전제가 적절한가?
- 추가 공간과 입력 저장 공간을 구분했는가?

## 완료 기준

- 모든 비용식에서 `n`, `V`, `E` 같은 변수의 의미를 먼저 정의한다.
- 최악·기대·상각 비용과 출력 크기 하한을 구분한다.
- 라이브러리 호출, 재귀 stack, 복사까지 포함해 공간 비용을 다시 계산한다.

## 실패 조건

- `O(n)`이라고 쓰면서 `n`의 의미가 없다.
- 평균과 상각을 같은 의미로 사용한다.
- 그래프를 항상 `O(V²)` 또는 항상 `O(V+E)`라고 단정한다.
- 재귀 stack이나 결과 저장 공간을 무시한다.
- benchmark 한 번을 점근 증명으로 취급한다.
