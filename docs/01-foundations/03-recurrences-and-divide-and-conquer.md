# 점화식과 분할 정복

## 학습 목표

- 재귀 호출과 현재 호출의 작업을 분리해 점화식을 세운다.
- 전개, 재귀 트리, 치환과 마스터 정리를 조건에 맞게 사용한다.
- 분할 정복에서 분할·정복·결합의 정확성과 비용을 따로 설명한다.
- 균등하지 않은 분할과 최악의 재귀 깊이를 식별한다.

## 선행 개념

[점근 분석](02-asymptotic-analysis.md)의 증가율 비교와 재귀 호출이 더 작은 입력을 만드는 과정을 설명할 수 있어야 한다.

## 핵심 모델

재귀 비용은 다음 형태로 분해한다.

```text
T(문제 크기) = 하위 문제들의 총비용 + 현재 호출의 비재귀 작업
```

점화식은 코드 모양을 옮겨 적는 것이 아니라 입력 크기가 어떻게 줄고 어떤 작업이 반복되는지 나타낸다.

## 1. 대표 점화식

| 점화식 | 해 | 구조 |
|---|---|---|
| `T(n)=T(n-1)+Θ(1)` | `Θ(n)` | 한 원소씩 감소 |
| `T(n)=T(n/2)+Θ(1)` | `Θ(log n)` | 이분 탐색 |
| `T(n)=2T(n/2)+Θ(1)` | `Θ(n)` | 완전 이진 재귀 |
| `T(n)=2T(n/2)+Θ(n)` | `Θ(n log n)` | 병합 정렬 |
| `T(n)=T(n-1)+T(n-2)+Θ(1)` | 지수 증가 | 중복 하위 문제 |

## 2. 전개와 재귀 트리

`T(n)=T(n/2)+c`를 펼치면 문제 크기가 1이 될 때까지 약 `log₂ n`단계가 필요하므로 `Θ(log n)`이다.

`T(n)=2T(n/2)+cn`에서는 각 레벨의 지역 작업 합이 `cn`이고 레벨 수가 `Θ(log n)`이므로 전체는 `Θ(n log n)`이다.

재귀 트리를 그릴 때 확인할 것은 세 가지다.

1. 레벨 수
2. 한 레벨의 노드 수
3. 각 노드의 지역 작업과 레벨 전체 합

## 3. 마스터 정리의 사용 범위

`T(n)=aT(n/b)+f(n)` 꼴이라도 다음을 확인한다.

- 하위 문제 크기가 실제로 거의 균등한가?
- `a`와 `b`가 입력에 따라 변하지 않는가?
- `f(n)`이 분할과 결합을 포함한 현재 호출 전체 작업인가?
- `T(n-1)`이나 서로 다른 크기의 하위 문제를 억지로 끼워 맞추지 않았는가?

공식을 적용한 뒤 전개나 재귀 트리로 결과의 방향을 검산한다.

## 4. 분할 정복 설계

```text
분할: 원래 문제를 더 작은 독립 또는 결합 가능한 문제로 나눈다.
정복: 하위 문제를 재귀적으로 해결한다.
결합: 하위 결과로 원래 문제의 결과를 만든다.
```

좋은 분할은 다음을 만족한다.

- 각 하위 문제의 계약이 원래 문제와 같은 형태다.
- 문제 크기가 엄격히 감소한다.
- 하위 결과를 결합할 충분한 정보가 있다.
- 분할과 결합 비용이 재귀 이득을 없애지 않는다.

## 5. 예제: 역전 쌍 수

정수열에서 `i < j`이고 `A[i] > A[j]`인 쌍을 센다.

단순 기준은 모든 쌍을 비교하는 `Θ(n²)`다. 병합 정렬 구조를 사용하면 각 절반 내부의 역전은 재귀적으로 세고, 병합 중 두 절반을 가로지르는 역전을 센다.

```text
T(n)=2T(n/2)+Θ(n)=Θ(n log n)
```

병합에서 오른쪽 현재 값이 왼쪽 현재 값보다 작으면, 정렬된 왼쪽의 남은 모든 값과 역전을 만든다.

### 정확성 분해

모든 역전 쌍은 정확히 하나에 속한다.

1. 왼쪽 절반 내부
2. 오른쪽 절반 내부
3. 두 절반을 가로지름

재귀 호출이 1·2를 정확히 세고 병합이 3을 정확히 한 번 세면 전체 결과가 맞다.

## 6. 균형이 깨지는 재귀

퀵정렬의 partition이 매번 `0`과 `n-1`로 나뉘면 다음이 된다.

```text
T(n)=T(n-1)+Θ(n)=Θ(n²)
```

평균 또는 기대 `O(n log n)`이라는 주장과 최악 `O(n²)`이라는 주장을 분리한다. pivot 무작위화가 입력 분포가 아니라 알고리즘의 무작위성에 대한 기대 비용을 만드는지도 구분한다.

## 7. 종료 증거

재귀 정확성에는 종료도 포함된다.

- 정수 크기가 매번 감소한다.
- 구간 길이가 줄어든다.
- 아직 처리하지 않은 정점 수가 감소한다.
- 유한한 상태 공간에서 이미 방문한 상태를 다시 확장하지 않는다.

감소량이 음수가 되지 않는다는 것도 보여야 한다.

## 완료 기준

- 재귀 호출 수, 하위 문제 크기, 결합 비용을 각각 분리해 점화식을 쓴다.
- 선택한 해법으로 점근 상한을 유도하고 적용 전제를 확인한다.
- 모든 재귀 경로에서 감소하는 정수량과 기저 사례 도달을 설명한다.

## 실패 조건

- 하위 문제의 크기를 쓰지 않고 호출 횟수만 센다.
- 결합 비용을 누락한다.
- 마스터 정리를 `T(n-1)`에 적용한다.
- 평균적으로 균형 잡힌 분할을 최악 보장으로 표현한다.
- 기저 사례는 있지만 문제 크기가 줄지 않는다.
