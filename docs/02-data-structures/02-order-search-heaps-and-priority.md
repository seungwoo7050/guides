# 순서, 탐색, 힙과 우선순위

## 학습 목표

- 정렬이 어떤 질의를 싸게 만드는 전처리인지 설명한다.
- 이분 탐색의 구간·판정 함수·동점 계약을 명시한다.
- heap의 보장과 정렬된 구조의 보장을 구분한다.
- 값의 답을 직접 찾지 않고 결정 문제로 바꾸는 parametric search를 설계한다.

## 선행 개념

[선형 구조와 구간](01-linear-structures-ranges-and-hashing.md), 비교 관계와 이진 탐색의 구간 불변식을 알고 있어야 한다.

## 핵심 모델

순서를 만들면 일부 연산은 빨라지지만 갱신 비용이나 원래 순서를 잃는 비용이 생긴다.

```text
정렬 비용 + 이후 질의 비용 + 갱신 비용 + 원래 순서 보존 비용
```

## 1. 정렬을 선택하는 이유

정렬 후 가능한 일:

- 같은 값 묶기
- 두 포인터
- 이분 탐색
- sweep line의 사건 순서
- 그리디 선택 순서 고정
- 중복 제거와 순위 계산

한 번만 질의하는 작은 입력에서 정렬이 항상 이득인 것은 아니다. 여러 질의나 이후 선형 처리가 정렬 비용을 상쇄하는지 계산한다.

## 2. lower bound 계약

정렬된 수열 `A`에서 첫 `A[i] >= target` 위치를 찾는다. 존재하지 않으면 `n`을 반환한다.

반열린 구간 `[lo, hi)`를 사용한다.

```text
while lo < hi:
    mid = lo + floor((hi-lo)/2)
    if A[mid] < target:
        lo = mid + 1
    else:
        hi = mid
return lo
```

불변식:

```text
lo 앞은 모두 target보다 작다.
hi부터 뒤는 모두 target 이상이다.
0 <= lo <= hi <= n이다.
```

`upper bound`는 첫 `A[i] > target` 위치다. 두 경계를 빼면 target의 개수를 구할 수 있다.

## 3. 경계 탐색의 오류

- 닫힌 구간과 반열린 구간 공식을 섞음
- `mid`가 변하지 않아 무한 반복
- 첫 참/마지막 참의 반환 위치 혼동
- 중복에서 임의 일치 위치를 반환
- 정렬 전조건 누락
- 정수 overflow가 가능한 `(lo+hi)/2`

한 구현에서는 구간 표현을 끝까지 하나로 유지한다.

## 4. 답에 대한 이분 탐색

답 `x`에 대해 판정 함수 `feasible(x)`가 단조라면 값 영역을 이분 탐색할 수 있다.

예:

```text
용량 x로 모든 작업을 제한 시간 안에 처리할 수 있는가?
거리 x 이상으로 k개 지점을 선택할 수 있는가?
최대 작업량을 x로 제한해 구간을 m개 이하로 나눌 수 있는가?
```

먼저 단조 방향을 증명한다.

```text
feasible(x)가 참이면 모든 더 큰 x도 참이다.
```

그리고 찾는 경계가 첫 참인지 마지막 거짓인지 명확히 한다.

## 5. heap

min-heap은 전체 정렬을 유지하지 않는다. 오직 root가 최솟값이고 부모가 자식보다 우선한다는 부분 순서만 유지한다.

| 연산 | 일반 비용 |
|---|---:|
| 최소값 확인 | `O(1)` |
| 삽입 | `O(log n)` |
| 최소값 제거 | `O(log n)` |
| 임의 값 탐색 | 일반적으로 `O(n)` |
| n개에서 heap 구축 | `O(n)` 가능 |

“상위 k개”나 “다음 처리할 최소 비용 상태”처럼 전체 정렬이 필요하지 않을 때 적합하다.

## 6. lazy deletion

heap에서 임의 항목 삭제가 어렵다면 최신 상태를 별도 map에 두고 pop할 때 오래된 항목을 버릴 수 있다.

```text
heap에는 후보가 여러 버전 존재할 수 있다.
map에는 각 key의 최신 version이 있다.
pop한 항목의 version이 최신과 다르면 폐기한다.
```

불필요한 항목이 계속 쌓일 수 있으므로 메모리 상한과 정리 정책도 고려한다.

## 7. 비교 함수와 전체 순서

정렬·heap의 비교는 일관된 엄격 약순서를 제공해야 한다.

- `a < a`는 거짓
- `a < b`와 `b < a`가 동시에 참이면 안 됨
- 비교의 추이성이 유지됨
- 동점 규칙이 명시됨

부동소수점 NaN, mutable 필드, 실행 중 바뀌는 외부 상태는 비교 계약을 깨뜨릴 수 있다.

## 완료 기준

- 탐색 구간과 `answer` 후보를 포함한 lower bound 불변식을 적는다.
- 답 이분 탐색의 판정 함수가 한 방향으로만 바뀜을 증명한다.
- heap 동점 규칙과 lazy entry 폐기 조건을 재현 가능한 예제로 확인한다.

## 실패 조건

- heap을 정렬된 배열처럼 임의 순위 탐색에 사용한다.
- 답 이분 탐색에서 판정 함수의 단조성을 증명하지 않는다.
- 중복 값의 첫 위치와 임의 일치를 혼동한다.
- lazy deletion에서 최신 여부를 확인할 식별자가 없다.
- 비교 함수가 동점이나 추이성을 정의하지 않는다.
