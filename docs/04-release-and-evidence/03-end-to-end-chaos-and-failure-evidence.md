# 종단 간 장애 실험과 근거

## 목표

장애를 무작위로 일으키는 데 그치지 않고, 하나의 실패 가설을 장애 전·중·복구 후의 업무 상태와 근거로 검증합니다.

## 문제

서비스별 단위 검사와 통합 검사가 모두 통과해도 실제 조합에서는 다음 문제가 남습니다.

- 설정 이름과 channel이 어긋납니다.
- migration과 application 시작 순서가 맞지 않습니다.
- retry가 여러 계층에서 증폭됩니다.
- broker 복구 뒤 Outbox가 따라잡지 못합니다.
- projection은 실행 중이지만 일부 이벤트를 잃었습니다.
- cleanup이 실패하면서 원래 검사 종료 코드를 가립니다.

여러 장애를 한꺼번에 주입하면 원인과 복구 계약을 판단하기 어렵습니다.

## 계약

### 실패 가설을 먼저 적습니다

실험은 다음 문장으로 시작합니다.

```text
[조건]일 때
[사용자 또는 업무 영향]이 발생하지만
[바뀌면 안 되는 상태]는 유지되고
[복구 행동] 뒤
[최종 상태]로 [시간 한도] 안에 수렴합니다.
```

예:

```text
broker가 30초 중단되면 새 예약의 Outbox가 쌓이지만
예약 상태와 event ID는 보존되고,
broker 복구 뒤 60초 안에 projection이 원본과 같은 개수로 수렴합니다.
```

### 한 번에 하나의 실패를 주입합니다

실험 단계는 고정합니다.

1. 빈 상태 또는 고정 fixture에서 시작합니다.
2. 장애 전 기준 상태를 측정합니다.
3. 실패 하나를 주입합니다.
4. 장애 중 요청과 업무 상태를 기록합니다.
5. 복구 전에 증거를 보존합니다.
6. 실패를 제거합니다.
7. 자동 복구 또는 재조정을 실행합니다.
8. 최종 상태와 시간 한도를 검사합니다.
9. 생성한 자원을 정리합니다.

실패가 여러 개 필요한 시나리오는 앞선 단일 실패 실험이 모두 독립적으로 통과한 뒤 조합합니다.

### 증거를 복구보다 먼저 수집합니다

실패 직후 재시작하거나 queue를 비우면 원인이 사라질 수 있습니다. 다음을 먼저 저장합니다.

- 요청별 상태 코드와 operation ID
- 관련 서비스 로그와 trace
- DB 상태와 row count
- Outbox, DLQ와 projection checkpoint
- container·process 상태
- 주입한 실패와 시작·종료 시각
- 사용한 release manifest

증거 수집 자체가 실패할 수 있으므로 일부 자료가 없어도 원래 실패 상태를 보존합니다.

### 원래 종료 코드를 보존합니다

실험 본문이 실패한 뒤 cleanup도 실패할 수 있습니다. 최종 종료 코드는 원래 검사의 실패를 가리키고, cleanup 실패는 별도 결과로 남깁니다.

```text
primary_status = 1
cleanup_status = 2
final_status = 1
```

cleanup 성공이 잘못된 업무 결과를 성공으로 바꾸지 않습니다.

## 실패 조건

- 여러 서비스를 동시에 중단하고 한 번의 실험으로 봅니다.
- 기대하는 부정 불변 조건을 적지 않습니다.
- 실패 직후 재시작부터 수행합니다.
- 프로세스가 다시 실행된 사실만 복구 성공으로 판단합니다.
- cleanup 오류가 원래 실패 코드를 덮습니다.
- 이전 volume과 cache가 남은 상태에서 릴리스 검사를 반복합니다.
- 실패한 실행의 manifest와 식별자를 기록하지 않습니다.

## 검증

실험 실행기 자체도 검사해야 합니다.

- 기준 상태 없이 fault를 시작하면 거절합니다.
- 두 fault를 동시에 주입하려 하면 거절합니다.
- 실패 중 evidence를 cleanup 전에 수집합니다.
- primary failure와 cleanup failure를 별도로 보존합니다.
- 복구 뒤 업무 상태가 기대값과 다르면 프로세스 health와 무관하게 실패합니다.

## 완료 조건

- 실패 가설에 영향·부정 불변 조건·수렴 상태·시간을 포함합니다.
- 장애 전·중·복구 후 근거를 같은 operation ID로 연결합니다.
- 복구 전에 증거를 보존합니다.
- cleanup이 원래 실패 결과를 가리지 않게 만듭니다.
