# 런북: 잘못된 배포와 롤백

## 대상 증상과 사용자 영향

- 새 릴리스 직후 오류율, 지연 시간, 재시작 횟수 또는 업무 처리 실패가 증가합니다.
- 스모크 테스트는 통과했지만 배포 후 관찰 구간에서 문제가 나타날 수 있습니다.
- 데이터베이스 마이그레이션 때문에 단순히 이전 이미지로 롤백할 수 없을 수도 있습니다.

## 사전 안전 조건

- 추가 배포를 잠그고 같은 환경에서 여러 배포가 동시에 상태를 변경하지 못하게 합니다.
- `current`, `previous`, 후보 릴리스의 매니페스트와 실제 실행 중인 다이제스트를 보존합니다.
- 스키마, 설정, 비밀값의 호환성을 확인하기 전에는 이미지부터 바꾸지 않습니다.

## 1. 영향과 시간 상관관계 확인

```text
배포 시작·확정 시각
오류 시작 시각
영향받는 경로·사용자·비율
현재 릴리스 마커
최근 마이그레이션·비밀값 회전
```

배포와 오류 발생 시점이 가깝더라도 배포를 원인으로 단정하지 않습니다. 외부 의존 서비스와 호스트 자원 상태도 함께 확인합니다.

## 2. 실제 상태 확인

```sh
cd /srv/example
docker compose ps -a
docker compose config >/dev/null
docker compose images
docker compose logs --since 30m --no-color
```

매니페스트와 다음 항목을 비교합니다.

- 현재 릴리스의 정확한 다이제스트
- 이전 릴리스의 정확한 다이제스트
- DB 스키마 최소·최대 버전
- 설정 스키마 버전
- 필요한 비밀값 버전
- 스모크 테스트 경로

## 3. 롤백 가능성 판정

다음 조건을 모두 만족하면 자동 또는 신속 롤백의 후보입니다.

- 이전 이미지가 레지스트리에 남아 있습니다.
- 현재 DB 스키마가 이전 릴리스의 허용 범위 안에 있습니다.
- 현재 설정과 비밀값을 이전 릴리스가 읽을 수 있습니다.
- 데이터를 파괴하는 마이그레이션이 적용되지 않았습니다.
- 문제 릴리스만 제거하면 사용자 영향이 줄어들 것이라는 근거가 있습니다.

다음 상황에서는 자동 롤백을 중단하고 사람이 판단하거나 롤포워드를 검토합니다.

- 컬럼·테이블 삭제 또는 되돌릴 수 없는 데이터 변환이 적용됐습니다.
- 이전 릴리스가 새 스키마를 읽지 못합니다.
- 현재 릴리스와 이전 릴리스가 모두 같은 방식으로 실패합니다.
- 보안 사고 또는 데이터 정합성 위반 가능성이 있습니다.

## 4. 롤백 실행

```text
증거와 현재 상태 기록
→ 이전 매니페스트 재검증
→ 정확한 다이제스트 pull
→ 렌더링된 Compose 설정 검사
→ 필요한 호환 마이그레이션만 실행
→ 이전 릴리스 재생성
→ readiness 확인
→ 외부 스모크 테스트
→ current 릴리스 원자적 갱신
→ 관찰 구간
```

`latest`나 태그를 다시 해석하지 않습니다.

## 5. 롤포워드 선택

롤백보다 수정 릴리스를 앞으로 배포하는 편이 안전할 수 있습니다.

- 문제 범위가 작고 수정 사항을 검증했는가?
- 데이터 변환을 되돌릴 수 없는가?
- 수정 릴리스 준비 시간이 현재 사용자 영향보다 짧은가?
- 임시로 기능을 비활성화해 대응 시간을 확보할 수 있는가?

긴급 수정도 운영 호스트에서 직접 빌드하지 않습니다. 기존 CI, attestation, 매니페스트 경계를 그대로 유지합니다.

## 6. 가역적 완화

- 문제 기능 플래그 비활성화
- 특정 쓰기 경로를 유지보수 모드로 전환
- 트래픽·워커 수 제한
- 안전성이 확인된 이전 정확한 릴리스로 롤백

데이터를 임의로 수정해 코드 오류를 숨기지 않습니다.

## 7. 복구 확인

- 외부 읽기와 안전한 쓰기가 성공합니다.
- 오류율, 지연 시간, 재시작 횟수가 정상 범위로 돌아옵니다.
- 현재 상태 파일, 실제 다이제스트와 배포 기록이 일치합니다.
- 스키마, 설정, 비밀값 호환성을 다시 확인했습니다.
- 관찰 구간 동안 문제가 재발하지 않습니다.
- 실패한 릴리스가 자동으로 다시 배포되지 않도록 배포 게이트를 적용했습니다.

## 8. 증거와 후속 작업

```text
candidate·current·previous 매니페스트 다이제스트
실행 이미지 다이제스트 전후
마이그레이션 결과
스모크 테스트와 관찰 지표
롤백 또는 롤포워드 판단 근거
승인자·실행자
재발 방지 테스트·배포 게이트
```
