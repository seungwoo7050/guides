# 05 — 오류 경계

파서의 문법 오류, 저장소의 도메인 충돌과 최상위 입출력 오류를 분리합니다. 내부 예외 문자열을 외부 응답으로 그대로 노출하지 않고, 갱신은 검증을 마친 뒤 반영합니다.

## 구조

- `skeleton/main.cpp`: 오류 경계를 구현할 시작 코드
- `reference/main.cpp`: 비교용 구현
- `commit_failure.cpp`: 부분 갱신과 준비 후 반영 방식 비교
- `test.sh`: 외부 오류 응답 검사

## 실행

```sh
make observe
make exercise-test
make test
make fail-commit
```

## 부분 갱신 확인하기

여러 값을 기존 상태에 하나씩 직접 추가한 뒤 중간에서 예외를 발생시킵니다. 후보 상태에서 전부 검증한 뒤 `swap`하는 경우와 실패 후 상태를 비교합니다.

## 확인할 동작

문법 오류와 충돌 오류가 다른 응답으로 변환되고, 실패한 갱신 뒤 기존 공개 상태가 보존됩니다.
