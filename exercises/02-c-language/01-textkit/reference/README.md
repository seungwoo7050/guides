# textkit 기준 구현

이 디렉터리는 workspace 구현과 검증을 끝낸 뒤 비교하는 기준 구현입니다. 번호는 함수의 나열 순서가 아니라 작은 문자열 계약을 쌓는 **학습용 권장 구현 순서**입니다.

## 구현 순서

| 번호 | 책임 |
|---:|---|
| `1` | `NULL`을 빈 입력으로 취급하는 길이 탐색 경계를 고정합니다. |
| `2` | 같은 순회 정책으로 특정 byte의 출현 수를 셉니다. |
| `3` | `isspace` 입력 변환과 단어 내부/외부 상태 전이로 단어 수를 셉니다. |

Makefile, 공개 header, CLI와 test는 제공된 build graph입니다. `cc`, `ar`, `make`는 build·검증 도구이므로 `Implementation 0`이나 중간 구현 단계가 아닙니다.
