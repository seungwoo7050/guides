# 01. 분석과 반례

## 목표

코드를 작성하기 전에 문제의 의미와 검증 방법을 고정한다.

## 사용 시점과 기록 위치

답은 저장소 source가 아니라 저장소 밖 개인 학습 노트에 기록한다. Part 1을 읽은 직후에는 아래 공통 기록과 각 문제의 계약·기준 풀이·반례 초안을 작성한다. 아직 배우지 않은 알고리즘 이름으로 빈칸을 채우지 않는다.

```text
입력 크기 변수와 worst-case 비용
기준 풀이와 후보 풀이의 비용 차이
binary search·merge sort·최악 quicksort의 점화식과 base case
반복 불변식 또는 귀납 가정
상태가 strict하게 줄어드는 종료 근거
```

그 뒤 학습 경로에서 다시 돌아온다.

| 재방문 시점 | 완성할 문제 | 새로 사용할 근거 |
|---|---|---|
| Part 2 뒤 | A — 첫 삽입 위치 | 반열린 탐색 범위와 lower-bound 불변식 |
| Part 3 뒤 | B — 최대 구간 선택 | exhaustive oracle과 교환 논리 |
| Part 4 뒤 | C — 최단 경로 | Dijkstra 전조건과 Bellman–Ford 반복 불변식 |

## 문제 A — 첫 삽입 위치

정렬된 정수 수열과 target이 주어질 때 첫 `value >= target` 위치를 반환한다.

다음을 작성한다.

1. 빈 수열과 모든 값보다 큰 target의 결과
2. 반열린 탐색 구간의 불변식
3. 선형 기준 풀이
4. 중복 값에서 임의 일치 위치를 반환하는 결함의 최소 반례
5. 시간·추가 공간

## 문제 B — 최대 구간 선택

반열린 구간 중 서로 겹치지 않는 최대 개수의 구간을 고른다.

다음을 작성한다.

1. 잘못된 구간 입력의 처리
2. 시작 시간 우선 규칙이 실패하는 최소 반례
3. 종료 시간 우선 규칙의 교환 논리
4. 모든 부분집합을 사용하는 기준 풀이의 비용
5. 동점 정렬 규칙

## 문제 C — 최단 경로

가중 directed graph에서 한 시작점의 최단 거리를 구한다.

다음을 작성한다.

1. 음수 edge, 음수 cycle, 도달 불가능의 계약
2. Dijkstra 전조건
3. Bellman–Ford의 `k`번째 반복 불변식
4. 작은 graph에서 사용할 독립 기준 계산
5. reachable negative cycle과 unreachable negative cycle을 구분하는 입력

## 학습 노트 rubric

각 문제는 다음 8항목으로 확인한다.

```text
[ ] 입력·출력 계약이 완전하다.
[ ] 답 없음과 잘못된 입력이 구분된다.
[ ] 기준 풀이가 후보와 독립적이다.
[ ] 입력 크기 변수가 정의되어 있다.
[ ] 시간과 공간이 모두 있다.
[ ] 불변식이 검증 가능한 문장이다.
[ ] 종료 근거가 있다.
[ ] 최소 반례가 특정 가정을 깨뜨린다.
```

자동 채점은 하지 않는다. 증명 문장을 형식만 맞춰 통과시키는 것보다 반례와 논리의 타당성을 사람이 검토하는 편이 정확하다.

## 자가 검수 체크포인트

먼저 답을 작성한 뒤 아래 사실과 한 항목씩 대조한다. 결론만 같아도 불변식이나
반례가 이를 실제로 뒷받침하지 않으면 완료로 표시하지 않는다. 가능하면 수정한
답을 짝 검토자에게 다시 보여 준다.

- A: 빈 수열과 모든 값보다 큰 target의 답은 모두 `len(values)`다. lower bound의
  반열린 구간은 `lo` 왼쪽이 모두 target보다 작고 `hi` 이상이 모두 target 이상인
  경계를 보존해야 한다. `[1, 1]`에서 target `1`인데 두 번째 위치를 반환하면
  “아무 일치 위치” 구현의 최소 반례가 된다.
- B: `[(0, 3), (1, 2), (2, 3)]`에서 시작 시간 우선은 한 개만 고르지만 종료 시간
  우선은 두 개를 고른다. 교환 논리는 임의 최적해의 첫 구간을 가장 빨리 끝나는
  구간으로 바꿔도 뒤 후보를 잃지 않음을 보여야 한다.
- C: Dijkstra는 음수 edge를 거부해야 한다. Bellman–Ford는 시작점에서 도달 가능한
  음수 cycle만 오류로 보고하며, 작은 독립 기준은 후보와 같은 relaxation loop가
  아니라 Floyd–Warshall 같은 다른 계산 경로를 사용해야 한다.

## 완료 기준

- 입력 크기·점화식·불변식·종료 근거를 Part 1 공통 기록에 남긴다.
- 세 문제마다 입력·출력·오류·답 없음이 구분된 계약을 제출한다.
- 후보와 다른 계산 방법의 기준 풀이 및 시간·공간 비용을 적는다.
- 결함 가정 하나를 직접 깨는 최소 반례를 문제마다 하나 이상 남긴다.
