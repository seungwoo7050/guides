# number-report 기준 구현

이 디렉터리는 workspace 구현과 검증을 끝낸 뒤 비교하는 기준 구현입니다. 아래 번호는 Git 이력이 아니라 책임과 실패 경계를 쌓는 **학습용 권장 구현 순서**입니다.

## 구현 순서

| 번호 | 책임 |
|---:|---|
| `1` | 누적 통계의 단일 상태 모델과 불변식을 정합니다. |
| `2` | 문자열 하나를 `long`으로 완전히 변환하고 성공할 때만 출력값을 반영합니다. |
| `3` | 초기 상태와 오버플로 전 검사를 포함한 누적 전이를 구현합니다. |
| `4` | 확정된 상태를 stdout 계약으로 렌더링합니다. |
| `5` | CLI가 parsing, 누적, 오류 출력과 종료 상태를 조합하게 합니다. |

별도 project/dependency bootstrap이 없으므로 `Implementation 0`은 없습니다. 컴파일과 테스트 명령은 build·검증 절차이며 구현 번호에 포함하지 않습니다.
