# Learner tests

권장 test:

- dataset row·split join completeness
- forbidden feature exclusion
- preprocessing fit boundary
- known metric fixture
- threshold boundary
- training/evaluation mode
- artifact clean-process smoke
- schema compatibility와 invalid input

사용하는 library에 맞는 test runner를 선택한다. 공용 제출 검사기는 이 디렉터리의 test를 대신하지 않는다.
