# 명령 실행기

파이프와 입출력 리다이렉션을 해석해 외부 프로그램을 새 프로세스 그룹에서 실행하는 C 프로그램입니다. 부모가 `SIGINT`나 `SIGTERM`을 받으면 실행 중인 그룹에 같은 신호를 전달하고 마지막 명령의 종료 상태를 호출자에게 돌려줍니다.

## 빌드와 검사

```sh
make
make check
```

검사는 파이프와 리다이렉션, 4MiB 전송, 잘못된 문법, 명령 탐색 실패와 프로세스 그룹 신호 전달을 확인합니다.

## 실행

파이프와 리다이렉션을 포함한 명령줄 하나를 인자로 전달합니다. 따옴표는 단어를 묶는 용도로 지원하지만 변수 확장이나 명령 치환은 하지 않습니다.

```sh
./command_runner "printf 'hello\n' | wc -c"
./command_runner --dump "cat < input.txt | wc -c >> output.txt"
```

인자 개수가 맞지 않거나 명령줄 문법이 잘못되면 종료 코드 `2`를 반환합니다. 실행 파일을 찾지 못하면 `127`, 마지막 명령이 신호로 끝나면 `128 + signal`을 반환합니다.
